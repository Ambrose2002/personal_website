# Ambrose Blay Personal Website

Static personal academic website built with plain HTML and CSS.

## Local Preview

Run a local static server from the repository root:

```sh
python3 -m http.server 8001
```

Then open:

```text
http://localhost:8001
```

## GitHub Pages

This site is designed to deploy from the repository root on GitHub Pages. In the repository settings, enable Pages and select the `main` branch with `/ (root)` as the source.
